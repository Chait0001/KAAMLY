# Kaamly

Kaamly is a services marketplace mobile app built with React Native (Expo) and a Node.js + Express backend backed by MySQL. The first category is **cycle repair** — customers discover nearby cycle shops, pick a mechanic, and book a doorstep repair. The platform is designed to expand into many service categories over time, similar to JustDial, while keeping all current user-facing screens focused on the cycle-repair experience.
